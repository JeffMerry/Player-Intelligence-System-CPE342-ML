# บันทึกการทดลอง

สร้างไฟล์แยกตาม Task หรือการทดลอง โดยบันทึก:

- ผู้รับผิดชอบ วันที่ และ commit ที่ใช้
- เวอร์ชันข้อมูลและวิธีแบ่ง train/validation
- Preprocessing, features, model, hyperparameters และ seed
- คำสั่งรันและเวอร์ชัน dependencies
- Metric พร้อมวิธีเฉลี่ยหรือ threshold ที่ใช้
- ผล validation และผล Kaggle จริง (ถ้ามี) แยกกันชัดเจน
- ข้อสังเกต ข้อจำกัด และการทดลองถัดไป

ไม่ใส่คะแนนตัวอย่างที่อาจเข้าใจผิดว่าเป็นผลทดลองจริง
