# ผลทำนายและ Kaggle submission

เก็บผลแต่ละงานเป็น `task1.csv` ถึง `task5.csv` โดยมีคอลัมน์ `id,taskN`
ไฟล์รวมต้องตรงกับ sample submission ทางการและผ่านการตรวจสอบก่อนส่ง

ไฟล์ผลทำนายไม่ถูกติดตามโดย Git ให้บันทึกเวอร์ชันโค้ด โมเดล และผลการส่งจริง
ใน `reports/experiments/` เพื่อให้ย้อนกลับไปตรวจสอบได้
