# ข้อมูล

- `raw/TaskN/`: ข้อมูลต้นฉบับจากการแข่งขัน ห้ามแก้ไขต้นฉบับ
- `processed/TaskN/`: ข้อมูลที่ผ่าน preprocessing
- วาง `sample_submission.csv` ทางการที่ `raw/sample_submission.csv`

ข้อมูลในโฟลเดอร์นี้ไม่ถูกติดตามโดย Git ให้ทีมใช้แหล่งดาวน์โหลดเดียวกัน
บันทึกที่มา เวอร์ชัน และวิธีจัดวางข้อมูลใน README ของแต่ละ Task
ห้ามนำข้อมูล test ไปฝึกหรือ fit preprocessing โดยไม่มีข้ออนุญาตทางการ
